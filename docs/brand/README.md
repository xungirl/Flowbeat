## Construction (φ ≈ 1.618)
- Ring Ø = 1024 / φ · ring stroke = Ø / φ⁵ · gap = 360° / φ⁴
- Line length = ring inner Ø / φ · line stroke = ring stroke / φ
- Line segments flat : beat : wave = 1 : φ : φ²
- Wave = two circular arcs, R₂ = R₁ / φ · corner fillets r = R₂ / φ²
- Lockup: mark height M · cap height M / φ² · mark–text gap M / φ³ · margin M / φ²
- Keep the mark inside the central 80% circle (Apple Watch crop)
